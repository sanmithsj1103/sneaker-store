# 🐾 Puma 7. Sneaker Store

A fully designed multi-page sneaker e-commerce web application built using **HTML5 and CSS3**.

This project was developed as a Mini Project to demonstrate front-end development skills including layout structuring, Flexbox usage, UI design, and responsive web development.

---

## 📌 Project Overview

Puma 7. is an online sneaker selling web application consisting of:

- 🏠 Landing Page
- 👟 Product Display Page
- 🛒 Shopping Cart Page
- 💳 Payment / Checkout Page

The project focuses on clean UI design, structured layouts using Flexbox, and realistic e-commerce page flow.

---

## 🚀 Features

### 1️⃣ Landing Page
- Navigation bar with:
  - Logo (Puma 7.)
  - Menu links (Home, About, Brands, Contact)
  - Search icon
  - Cart icon
  - Profile picture
- Hero section with:
  - Catchy heading
  - Description
  - "Shop Now" button
  - Sneaker image
- Service Overview Section:
  - 2k+ Reviews
  - 30k+ Customers
  - High Quality
  - 4.5/5 Rating

---

### 2️⃣ Product Display Page
- Large product image
- Product name and description
- Price and discount details
- Quantity selector
- Add to Cart button
- Horizontal scrolling image gallery

---

### 3️⃣ Shopping Cart Page
- Shopping cart table with:
  - Product name
  - Quantity
  - Price
- Order summary card:
  - Coupon code input
  - Subtotal
  - Taxes
  - Discount
  - Total
  - Pay Now button
- Razorpay branding for realistic UI
- Continue Shopping link

---

### 4️⃣ Payment / Checkout Page
- Email input field
- Payment method options:
  - Card
  - Crypto
  - Bank
- Card details input:
  - Card number
  - Expiry date
  - CVV
  - Country
  - ZIP Code
- Order summary with final amount
- Pay Now button
